💻 Technical Events

Rules and regulations for all technical competitions.

🌐 Web Design

  • Participants must create a website within the given time.
  • HTML and CSS may be used for the competition.
  • The website must be responsive.
  • Participants must follow the given theme or problem statement.
  • Pre-made website templates should not be used.
  • The final website must be submitted before the deadline.

💻 Coding Challenge

  • Participants must solve the given programming problems.
  • Problems will test programming and logical thinking.
  • Participants must use the programming language specified by the organizers.
  • Each problem must be completed within the allotted time.
  • Solutions will be evaluated using test cases.

🤖 Robotics Challenge

  • Teams must complete the assigned robotics challenge.
  • Participants must follow all laboratory and equipment safety rules.
  • Only permitted components and equipment may be used.
  • Teams must complete the challenge within the given time.
  • Judging will consider functionality, accuracy, and innovation.

🧠 Tech Quiz

  • The quiz will consist of multiple rounds.
  • Questions may cover computers, technology, science, and innovation.
  • Each question will have a fixed time limit.
  • Use of electronic devices may be prohibited during the quiz.
  • The decision of the quiz coordinators will be final.
